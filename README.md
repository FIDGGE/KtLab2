Выполнил Гончаров Роман ПИ-251  
Цель работы  
Изучить механизм обработки пользовательских событий в Android-приложении с использованием языка Kotlin, освоить вывод всплывающих уведомлений Toast, вывод диагностических сообщений в Logcat с помощью стандартного класса Log и библиотеки Timber, а также программное динамическое изменение визуальных атрибутов элементов пользовательского интерфейса.   

Ход работы   

Шаг 1. Реализация всплывающего уведомления (ToastHandler)В файле разметки activity_main.xml был создан вертикальный контейнер LinearLayout и добавлена кнопка button_ok с текстом «ОК». В классе MainActivity был установлен слушатель клика setOnClickListener, вызывающий короткое всплывающее уведомление Toast с текстом «Кнопка ОК» длительностью Toast.LENGTH_SHORT.

Шаг 2. Логирование сообщений через стандартный класс android.util.LogВ разметку было добавлено поле ввода EditText и кнопка button_log («ЛОГИРОВАНИЕ LOG»). Для кнопки был реализован обработчик нажатия, считывающий введённую строку из EditText и отправляющий её на уровень подробного логирования Log.v с тегом "From EditText".

Шаг 3. Подключение библиотеки Timber и вывод логовВ файл конфигурации сборки build.gradle.kts модуля :app была добавлена зависимость com.jakewharton.timber:timber:5.0.1. В методе onCreate() выполнена инициализация дерева логирования Timber.plant(Timber.DebugTree()). В интерфейс добавлена кнопка button_timber, по клику на которую лог отправляется через Timber.v(), где тег определяется автоматически по имени класса активности.

Шаг 4. Динамическое изменение визуальных атрибутов EditTextВ разметку был добавлен блок из 6 кнопок управления стилем текстового поля. В коде активности к каждой кнопке привязаны соответствующие программные методы изменения свойств EditText:   Цвет текста: setTextColor(Color.BLACK) и setTextColor(Color.RED).   Размер шрифта: setTextSize(TypedValue.COMPLEX_UNIT_SP, 8f) и setTextSize(TypedValue.COMPLEX_UNIT_SP, 24f).   Цвет фона элемента: setBackgroundColor(Color.WHITE) и setBackgroundColor(Color.YELLOW).
